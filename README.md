# 💧 JM MOURA Distribuidora de Água

Landing Page desenvolvida para a **JM MOURA Distribuidora de Água**, com o objetivo de apresentar a empresa, seus produtos, diferenciais e facilitar o contato dos clientes por meio do WhatsApp.

## 🌐 Demonstração

Acesse o projeto:

🔗 https://jm-moura.vercel.app/

## 📖 Sobre o Projeto

Este projeto consiste em um site institucional de página única (One Page) para uma distribuidora de água mineral e bebidas.

A aplicação foi desenvolvida com foco em simplicidade, responsividade e experiência do usuário, permitindo que clientes visualizem os produtos oferecidos e entrem em contato rapidamente para realizar pedidos.

## ✨ Funcionalidades

- Apresentação da empresa
- Seção "Quem Somos"
- Exibição dos produtos comercializados
- Destaque dos diferenciais da empresa
- Depoimentos de clientes
- Informações de contato
- Integração direta com WhatsApp
- Layout responsivo para dispositivos móveis e desktop

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts (Poppins)

## 🚀 Como Executar

Clone o repositório:

```bash
git clone https://github.com/WesleySAlmeida/JM-MOURA.git
```

Entre na pasta do projeto:

```bash
cd JM-MOURA
```

Abra o arquivo `index.html` no navegador ou utilize uma extensão como **Live Server** no VS Code.
